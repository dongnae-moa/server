# **MVP (최소 구현 기능)**

- 동네 가입 (GPS 기반, Unique)
    - 동네 이동 가능 (GPS 기반으로 현재 동네 감지, 굳이 동네를 저장하지는 않아도 될 듯)
- 퀘스트 등록 / 삭제
    - 동네 단위로 퀘스트가 등록됨. 이때 퀘스트에 선택적으로 이미지 삽입 가능
- 퀘스트 참여 및 완료
    - 참여 : 자신의 동네의 퀘스트 참여 가능
    - 완료 : 퀘스트 등록자가 퀘스트 진행 후 올라온 인증을 보고 퀘스트 완료 여부 결정
- 퀘스트 달성에 대한 단체 보상 (게이미피케이션을 통한 동기 부여)
    - 일단은 캐시 지급

# 추가 구현 기능 (아직은 미구현)

- 동네 채팅(혹은 게시물) 기능 (퀘스트 하실분 모집 등)
- 퀘스트 보상에 대한 여러 사용처 (기프티콘, 프로필 장식, 근처 가게 할인 혜택 등 구매)
- 퀘스트 달성에 따른 랭킹 (경쟁을 통해 참여 촉진)
- 유저 신고 기능 (퀘스트 등록자 잠수 행위 방지 및 불건전한 활동 유저 처리)

# 예시

1. 공원에 쓰레기가 버려져 있음.
    1. 주민이 앱으로 문제점을 이미지와 함께 게시글로 제보
    2. AI 분석 -> 퀘스트 생성 (OO 지역 내 쓰레기 치우고 인증하기)
    3. 퀘스트를 본 유저들이 퀘스트를 진행함
2. 통행을 방해하는 공유 킥보드 & 자전거 치우기 미션
    1. A가 “인도 한복판에 있는 GCOO 옆으로 치우기” 미션 등록 -> 포인트 획득 (본인이 등록한 미션 본인이 해결 불가)
    2. B가 미션 수행 -> 포인트 획득
    3. C가 미션 수행 진위여부(B가 진짜 미션을 했는지) 확인 -> 포인트 획득
3. 지역 사회 단체 모금 행사
    1. 사진 인증 등을 통해 포인트 적립
4. 불법 주차 자동차 대신 신고
    1. 안전신문고에 신고해 담당자의 답변을 캡처 후 업로드하면 퀘스트 완료
